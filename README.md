# GradeTracker
Basic Grade Tracker that calculates your grades based on assignments.

## Installation

Clone the github repository

```bash
git clone git@github.com:CrChromium/GradeTracker
```

## Usage

To use the program, run the following commands

```bash
cd GradeTracker
python main.py
```

The program asks for the number of assignments you want to add, the name of each assignment, the category of each assignment, and the grade for each assignment.

Afterwards, it returns the grade for each subject (currently only math).
